Deep Dive Case Study

Real-Time Credit Card Fraud Detection Engine

The Problem:

Financial institutions face extreme class imbalance (<0.2% fraud transactions) where missing a fraud costs thousands, yet false alarms irritate legitimate customers.

The Solution:

Implemented a dual-tier ML architecture combining Isolation Forest (unsupervised outlier detection) with cost-sensitive XGBoost trained on SMOTE-resampled datasets.

Key Outcomes:
  • High precision with adjustable threshold tuning curve (F1-score optimized).
  • Automated tiered banking recommendations: Auto-Block, Step-up 2FA, or Auto-Approve.
  • Interactive FastAPI web dashboard deployed with millisecond inference speed.
